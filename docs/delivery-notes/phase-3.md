## What was delivered
By the end of Phase 3, the portal had a working student exchange application flow for both KU students and incoming students: users could start applications, save progress automatically, review submitted applications and status, export applications as PDFs, and request withdrawals when needed. Coordinators could also review historical applications, export student applications, see whether nominees had applied, and approve or reject withdrawal requests.On the instructions of the build lead, aysha implemented global state management from a centralized store using a redux-flow-like library
