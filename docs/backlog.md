# Backlog

The living backlog is the **Issues** tab. This file is a copy of it, saved at the end of
each sprint, so the list has a history and the delivery note has something to point at.

The Client Lead updates it. Delete the two example rows below before your first save. One section per phase, newest at the bottom. Keep it short —
the story ID, the title, who built it, and what happened to it.
